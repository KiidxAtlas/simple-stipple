Getting Started

What is Simple Stipple?

Simple Stipple is a desktop application that generates intricate laser-engraving patterns inside user-defined outlines. You draw or import an outline, choose a pattern and its parameters, and the software fills the area with mathematically precise vector geometry ready for your laser cutter.

Before You Start

  • Use Draft to draw or clean geometry, Pattern to fill an outline, Trace to turn an image into paths, Convert for file-format utilities, and Repository to sync files with Git.
  • On first launch a Welcome window offers these tasks and opens the matching page. Reopen it any time from Help → Welcome….
  • Save a workspace when you want to return to the same pages, geometry, and settings later.
  • Simple Stipple prepares geometry; it does not control laser hardware. Always preview and verify exported files in your machine software before enabling the laser.

Quick Start — Your First Pattern

  1. Open the Pattern page from the tab bar at the top (or press Alt+2).
  2. Load an outline — either draw one using the drawing tools (press D) or import a DXF, FVI, or SVG file via the Browse… button.
  3. Select a pattern from the dropdown (e.g., "Honeycomb").
  4. Adjust parameters — size, gap, spacing — using the sidebar controls. The preview updates as you change them; Rebuild preview regenerates it from the current settings.
  5. Export the result (for example Export DXF…) for your laser cutter.

The Five Pages

Page Default shortcut Purpose
DraftAlt+12D drafting — draw, edit, import/export DXF/SVG geometry.
PatternAlt+2Fill outlines with one of 10 built-in laser-engraving patterns (Basketweave, Brick, Grip Stipple, Honeycomb, Knurling, Mesh, Seigaiha, Stipple Dots, Truchet, Voronoi) or your own Custom Tile.
TraceAlt+3Convert images to vector outlines (tracing).
ConvertAlt+4Utilities — FVI→DXF, SVG↔DXF conversion, repair.
RepositoryAlt+5Sync a project folder with Git — pull, commit, push, or auto sync.

Switch pages with the tab bar, the command palette, or the shortcuts above (on macOS, Alt is ⌥ Option). Shortcuts can be changed in Settings → Keybindings; Help → Keyboard Shortcuts… always shows your current keys.

All pages belong to one workspace. Saving the workspace stores every page together; until you save, only crash-recovery snapshots protect your work (see Files, Workspaces & Recovery).
