Repository Sync — Git Workflow

Overview

Repository (File ▸ Open Repository, Alt+5) provides a simplified Git workflow for managing your project repository directly from the application.

Setup

  1. Select repository folder: Browse to your Git repository root directory.
  2. The page will automatically detect and display the current repository status.

Workflow Cards

Pull

Pull the latest changes from the remote repository. This fetches and merges updates from your configured remote.

Commit

Stage all changes and commit with a message. The default message is "Update project files" but you can customize it.

Push

Push committed changes to the remote repository. This is marked as a primary action (highlighted button).

Auto Sync

Turn on Auto sync this repository (also in File ▸ Auto Sync Repository and Settings) to keep the selected folder and its remote in step without pressing any buttons:

  • Local changes: edited or newly added files are committed a few seconds after saving stops, then pushed. Remote commits are pulled in first, so the push is not rejected.
  • Remote changes: checked every minute and pulled whenever no local edits are waiting to be committed.
  • Conflicts: if the same file changed on both sides, Auto sync undoes the attempted merge, leaves your files untouched, and pauses. Use Pull to resolve it, then turn Auto sync back on.

The line under the toggle shows the last result, such as "Synced at 14:02 (pulled 1, pushed 0)" or the reason syncing stopped. Every sync that commits, pulls, or pushes — and every new failure or conflict — also appears in Git output under an "Auto sync" heading, with each git command and its result; routine checks that find nothing to do are left out. The branch must already have a remote branch; push it once with Push first.

Secondary Actions

  • Status: Show the current repository status (modified files, staged changes, branch info).
  • Open Folder: Open the repository folder in Finder.

Git Log

The right panel displays the Git log showing recent commits with:

  • Commit hash and message
  • Author and date
  • Branch information

Settings Integration

The repository folder path is persisted in your settings and remembered between sessions. You can configure the default repo directory in Settings.
