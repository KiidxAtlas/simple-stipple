Files, Workspaces & Recovery

Workspace or export file?

  • Workspace: preserves pages, editable geometry, parameters, and app state so you can continue later.
  • DXF/SVG/FVI export: creates an interchange or production file. It is not a complete editable workspace.

Safe working routine

  1. Use File → Save Workspace early and give the job a recognizable name.
  2. Use File → Browse Workspaces… to browse and reopen named jobs, or File → Open Recent for the last few. The header's Workspace menu offers the same actions.
  3. Export only after fitting the view, checking layers, closed outlines, region treatments, and dimensions.
  4. Open the exported file in your machine software and verify scale, units, layers, and operation order.

Autosave and crash recovery

There are two separate kinds of automatic writes. Hover the workspace name in the header to see the time of each.

  • Saved to <workspace>: once a workspace has a name, unsaved changes are written to that file every 60 seconds.
  • Recovery snapshot: every 90 seconds while there are unsaved changes, a crash-recovery snapshot is written to the app's data folder. It is not a workspace save and is removed when you save the workspace or close without unsaved changes.

When you close with unsaved changes and choose Discard Changes, the latest recovery snapshot is kept (changes after it are lost; the dialog shows its time). Kept snapshots are offered the next time Simple Stipple starts, and stay in File → Recover Unsaved Work… until you restore or delete them. Inspect a snapshot there before restoring or permanently deleting it.

Importing and moving work

Draft accepts vector geometry for editing. Trace accepts bitmap images. Use Send to Draft or Send to Pattern when the next step is in another page; this keeps the geometry inside the current workspace.

StarFX FVI conversion supports geometry commands including MOVEDIST, DRAWLINE, and DRAWARC. Machine-control commands are reported as unsupported rather than silently converted.
