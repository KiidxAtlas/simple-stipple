Trace Page — Image to Outline.

Overview

The Trace page converts raster images (PNG, JPG, JPEG, BMP, TIFF, GIF, WebP) into vector outlines suitable for laser cutting. The left Settings pane holds the source and trace settings; the right Inspector holds the Image placement panel, the layer list, and the export and next-step buttons. In a narrow window each pane folds into a drawer with a Show/Hide button.

Workflow

  1. Open an image — drag and drop it onto the page, type its path, choose Browse, or pick one from Recent files.
  2. Tune the trace — the preview retraces automatically after each change (see Trace Settings and Advanced below).
  3. Place the image if needed — drag it on the canvas or type exact values in the Image panel.
  4. Export or continue — Export DXF…, or send the outlines to Draft or Pattern with the Next button.

Source

  • Image path, Browse, Recent files: choose the picture to trace.
  • Show image in background: draws the faded source behind the outlines. Hiding it keeps the placement and the outlines.

Trace Settings

Each number field shows its unit and valid range in its tooltip and placeholder. Fields accept arithmetic such as 25/2. A typed value is applied when you press Enter or leave the field; the slider under a field retraces while you drag it. The trailing ✕ in a field restores its default. An invalid entry stays in the field, outlined in red, with the reason in its tooltip and the status line — the preview keeps the last valid result until you correct it.

  • Blur radius (px): Gaussian blur applied before thresholding or edge detection; smooths noise. 0 or more (slider 0–5).
  • Edge mode (line art / Canny): traces edges with Canny edge detection instead of a brightness threshold — better for sketches and thin strokes. It swaps the threshold controls for Canny low and Canny high (1–255): edges weaker than Canny low are dropped, edges stronger than Canny high are always kept.
  • Auto threshold (Otsu): picks the brightness cutoff automatically. Turn it off to set Threshold (0–255) yourself: pixels darker than the threshold become shapes.
  • Invert (dark → light): swaps foreground and background.
  • Width / Height: output size in canvas units (mm or in, set in Settings), not image pixels. Image cleanup controls such as blur and simplify use source-image px. With Lock aspect ratio checked, changing either dimension derives the other; the live image-size line shows source px and current output dimensions. The reset control (✕) restores that field’s current default.

Advanced

  • Simplify (px): polygon simplification tolerance — higher values give fewer points. 0 or more (slider 0–10).
  • Min area (px²): discards contours smaller than this area; raise it to drop specks. 0 or more (slider 0–1000).
  • Max area (px²): discards contours larger than this area; leave it empty for no limit.
  • Closing radius (px): morphological closing that bridges small gaps so outlines close. 0 or more (slider 0–20).
  • Outer contours only (skip holes): keeps only outermost outlines, dropping interior holes such as the counters in A, B, and O.
  • Max resolution (px): largest pixel dimension used when loading the image, 64–8000. Higher values give finer detail but trace more slowly.

Preview and Status

  • Refresh Preview retraces immediately. While a trace runs it reads Restart Trace and abandons the running trace for a fresh one.
  • While a retrace is pending or running, the status line reads Preview out of date and the previous outlines stay visible. A progress bar shows the tracing stages.
  • When a trace finishes, the status line lists the contour count — with the change from the previous trace, such as (+3 vs previous) — the output size, vertices, and how many outlines are closed or open.
  • Smooth Curves… fits every outline to smooth curves once, at a tolerance you enter; Undo reverts it and the next retrace starts over.

Placing the Image

Turn on Adjust Image in the canvas toolbar and click the image to move it, pull a corner to scale it (proportions are kept and the trace refreshes at the new size), or drag the top handle to rotate it (Shift snaps). Dragging needs the image shown in the background. The outlines follow the image.

For exact values use the Image panel in the Inspector, which works whether or not the image is shown: X/Y (the bottom-left corner before rotation), W/H (proportions kept), Center on bed and Fit to bed (largest size that fits the machine bed at the current rotation, keeping proportions, then centred — set the bed size in Settings first), an absolute Rotation, R +90 / R -90, and Reset. Fields accept arithmetic and units such as 25/2 or 1in + 3mm, like Draft's Properties; an invalid entry is kept and outlined in red with the reason in its tooltip. Remove Image, or Delete while the image is selected, unloads it and keeps the outlines.

Export and Next Steps

  • Export DXF… saves every traced outline. The Format menu also offers Export Selected as DXF…, Export Raster Engraving… (a grayscale PNG with position and laser settings), and revealing the last export. If the export check finds problems, Show Issues selects the affected outlines and zooms to them.
  • The Next button names its destination — Next — Edit in Draft, Next — Use in Pattern, or Next — Export DXF…; change it with the Next step menu beside it. It sends the selected outlines, or all of them when nothing is selected.
  • Pattern uses closed outlines only. If some traced contours are open, Trace says how many will be excluded and offers to send the open ones to Draft to close them; if none are closed it explains why and offers Draft instead. The canvas context menu's Send to Pattern does the same check.

Tips

  • High-contrast images work best. Black-and-white or high-contrast pictures trace most accurately; photographs may produce noisy outlines.
  • Noisy result? Raise Blur radius or Min area.
  • Outlines not closing? Raise Closing radius, or turn off Edge mode.
  • Nothing traced? Try Invert, or turn off Auto threshold and adjust Threshold.
