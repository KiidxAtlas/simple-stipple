Convert Page — Utilities & Conversion

Overview

The Convert page converts and repairs DXF, SVG, and FVI files. Choose a task in the left Settings pane, set the input in the INPUT bar at the top (type a path, choose Browse…, drop a file or folder, or pick from Recent files), then run the task with the button at the bottom of the pane. In a narrow window the Settings pane folds into a drawer with a Show/Hide button.

Tasks

FVI to DXF

  • FVI is the FiberStar/StarFX laser vector format.
  • Single file or Folder (batch) mode.
  • Output: optional folder — blank writes each DXF beside its source.

Repair DXF

  • Safe repair fixes only damaged polylines and keeps layers and native entities. Flatten for laser rebuilds supported geometry as polylines on layer 0.
  • Repairs close near-open paths, simplify redundant vertices, and discard degenerate geometry.
  • Output: optional — blank writes a non-destructive -fixed copy (a sibling -fixed folder in batch mode). A batch output folder must be outside the source folder.

DXF to SVG / SVG to DXF

  • DXF to SVG exports DXF polylines as an SVG graphic; SVG to DXF converts SVG paths to DXF polylines. Unsupported curved paths or SVG features are listed in the result.
  • Batch mode needs an output folder.

Folder (batch) mode

  • Include subfolders is shown under the mode buttons for every task and takes effect in Folder (batch) mode. When on (the default) files are found in all nested folders and the folder structure is kept in the output; when off only the top folder is used. The status line states the choice when you switch to batch mode or toggle it, and the log and final summary repeat it.
  • If any outputs already exist, a confirmation says how many will be replaced; Show Details lists every file.
  • The progress bar under the run button fills file by file (a single file shows a moving bar), and the status line shows the current file and elapsed time. Options ▸ Cancel Active Job stops after the current file and keeps finished outputs.
  • When the run ends the status line under the run button reads N converted, M failed, with warnings or skips. If a file failed, the File results list opens with the first failure selected and its message shown in the status line.

Results

  • File results keeps the file list beside the selected output preview and full LOG. Selecting a row shows its status, paths, and message, and loads its preview when it has geometry. Open output opens the selected successful file; Open in Draft and Use in Pattern send that selected geometry to the chosen page. Retry failed reruns failed files only.
  • The LOG panel records each file, warnings, and the batch summary.

Status Colors

  • Green: completed without problems.
  • Amber: completed with warnings, skips, or some failed files.
  • Red: the operation failed — the message says why.
  • Gray: progress and neutral information.

Ignored Entities

Unsupported DXF entities are skipped during conversion; the result shows how many were ignored and of which types.
