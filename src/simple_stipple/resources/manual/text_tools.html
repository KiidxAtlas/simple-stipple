Text & Typography

Select a text object and press T to edit its text, font, height and style. With no text selected, T opens Add Text. Select only one text object when editing; all of its grouped contours count as one object. The dialog supports multi-line text — press Enter inside the text box for a new line. Accepting without changes preserves the original artwork, including cached StarFX glyphs. Changing imported text redraws it with the selected local font; the original font must be installed for matching glyphs.

To flow a text object along an existing path: select exactly one text object and one open path, then use Attach Text to Path (command palette or right-click menu). Each character's contour is repositioned and rotated to sit tangent to the path at even spacing. Editing the text later ("Rebuild Text") re-flows it along the same path automatically.
