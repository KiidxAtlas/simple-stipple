Pattern Types — Complete Guide

The Pattern list offers ten built-in generators — Basketweave, Brick, Grip Stipple, Honeycomb, Knurling, Mesh, Seigaiha, Stipple Dots, Truchet, and Voronoi — plus Custom Tile and any custom tiles you have saved. Image in the same list is not a generator: it gives the selected region the Engrave treatment.

Every length is in millimetres. Hover a field to see its allowed range; type an exact value (or an expression such as 25/2) and press Enter, or drag its slider. The default values below are what a new document starts with.

Repeat mode is available on every pattern: Straight stacks rows directly, Half drop shifts every other row by half a repeat, and Brick offset by a third. Stipple Dots, Grip Stipple, and Voronoi also offer Off (random), their default free scatter; any other mode builds one random tile of Repeat size (mm) and repeats it with no crowding or broken cells at the seams. On Knurling the stagger applies to the diamond (cross-hatch) knurl. Align to region anchors a lattice to the region itself instead of the shared document grid — use it to centre a motif in one region.

Tilings

Honeycomb

A hexagonal grid, ideal for structural engraving and decorative surfaces.

Hex size (mm)Radius of each hexagonal cell (default: 1.75 mm)
Gap (mm)Spacing between adjacent hexagons (default: 0.5 mm)
Repeat modeDefault: Half drop

Brick

Brickwork with staggered rows.

Brick width (mm)Width of each brick (default: 4.0 mm)
Brick height (mm)Height of each brick (default: 2.0 mm)
Gap (mm)Mortar gap between bricks (default: 0.5 mm)
Repeat modeDefault: Half drop

Basketweave

Alternating horizontal and vertical strips that read as a woven basket.

Strip width (mm)Width of each woven strip (default: 2.0 mm)
Strip length (mm)Length of each woven strip (default: 8.0 mm)
Gap (mm)Gap between woven strips (default: 0.2 mm)
Repeat modeDefault: Straight

Mesh

A regular grid of circles.

Circle radius (mm)Radius of each mesh circle (default: 0.35 mm)
Grid spacing (mm)Centre-to-centre distance between circles (default: 1.2 mm)
Repeat modeDefault: Straight

Knurling

Machined-knurl grip: raised pads between straight grooves, in one family or crossed into diamonds.

Groove pitch (mm)Spacing between grooves; the diamond size follows from pitch and angle (default: 1.5 mm)
Groove angle (°)Angle of each groove family from horizontal, −89° to 89° (default: 30°)
Groove width (mm)The cut groove between raised pads (default: 0.3 mm)
Cross-hatch (diamond)On for diamond knurl; off for a single straight family (default: on)
Repeat modeDefault: Straight

Seigaiha

Japanese wave scales: overlapping rows of concentric arcs.

Scale radius (mm)Radius of each wave scale; rows overlap by half this value (default: 6 mm)
Rings per scaleConcentric arcs inside each scale, 1–12 (default: 3)
Ring spacing (mm)Distance between arcs within one scale (default: 1.2 mm)
Scale spacing (mm)Gap between neighbouring scales; 0 tiles the surface completely (default: 0.3 mm)
Repeat modeDefault: Half drop

Truchet

Square tiles of quarter-circle arcs, each randomly rotated; the arcs meet exactly at tile edges and form continuous flowing curves.

Tile size (mm)Edge length of each square tile (default: 6 mm)
Cell gap (mm)Space between cells; 0 leaves no room to fill around them (default: 0.3 mm)
SeedFixes the random tile rotations so a re-solve is reproducible (default: 1)
Repeat modeDefault: Straight

Random Patterns

Stipple Dots

Poisson-disk distributed dots for a stippled, pointillist surface.

Dot radius (mm)Radius of each dot (default: 0.4 mm)
Spacing (mm)Centre-to-centre distance between dots (default: 1.2 mm)
SeedRandom seed for repeatable placement (default: 42)
Repeat mode / Repeat size (mm)Default: Off (random); repeat tile 10 mm

Grip Stipple

Dense, randomly placed angular grains with narrow grooves, inspired by molded grip textures.

Element size (mm)Approximate radius of each irregular grain (default: 0.28 mm)
Spacing (mm)Minimum centre-to-centre distance between grains (default: 0.62 mm)
SeedRandom seed for repeatable grain placement and shapes (default: 42)
Repeat mode / Repeat size (mm)Default: Off (random); repeat tile 10 mm

Voronoi

Irregular polygonal cells partitioning the region.

Cell countNumber of random cells, 2–2000 — per repeat tile when Repeat mode is on; high counts slow previews (default: 60)
Gap (mm)Inset distance between cells (default: 0.15 mm)
SeedRandom seed for reproducible cell placement (default: 42)
Repeat mode / Repeat size (mm)Default: Off (random); repeat tile 10 mm

Custom Tiles

Choose Custom Tile, then right-click selected geometry on the canvas → Use as Custom Tile to repeat your own motif. Save custom tile adds it to the Pattern list as Custom · name; tiles in the configured tile folder appear there too. A saved tile remembers its own settings — choosing it loads them and the status line says Loaded saved settings for name.

Tile gap (mm)Spacing between repetitions of the motif (default: 0.5 mm)
Repeat modeStraight, Half drop, Brick offset, Mirror rows, Mirror columns, or Alternate 180° (default: Straight)
Align to regionAnchor the repeat to the region instead of the document grid (default: off)

Retired Patterns

Some older generators have been retired. A workspace or preset that uses one still opens: the pattern is replaced by its closest survivor and the status line names the substitution (for example Retired pattern replaced: Flow Lines → Truchet). Parameters of the retired pattern are not carried over, so review the replacement's settings and save the workspace to keep it.
