Pattern Page — Full Reference

Overview

The Pattern page fills closed outlines with engraving patterns. One workflow rail runs down the left in task order, the canvas and live preview stay centered, and the Inspector on the right is reserved for layers and selection. The rail scrolls through setup and treatment controls while its export action stays fixed at the bottom. On a narrow window, use the Settings and Inspector drawer buttons above the canvas.

Workflow rail

  • 1. Outline: load a DXF, FVI, or SVG outline (Browse…, Recent, drag-and-drop, or reload from disk).
  • 2. Pattern & Fill: choose a built-in generator, custom tile, or Image (see Pattern Types); adjust pattern parameters, Pattern modifiers, presets, the document Pattern grid, and optional laser fill.
  • 3. Regions & treatment: optionally assign a treatment to individual regions. Pattern and fill settings above apply to the selected region.
  • Export: choose a format and export. The compact summary shows the format, enabled operations, and preflight warnings. Open Output details for operation selection, ordering, geometry checks, and findings; Export options holds cleanup and preview settings.
  • Laser process: this disclosure controls only image-engraving power, speed, and passes. Image placement and removal remain available with the image controls.

Preview

There is no Generate step: the preview re-solves automatically whenever a setting changes. Typed values apply when you press Enter or leave the field; sliders, checkboxes, and lists apply as you change them. Preview quality (Export options) trades preview detail for speed only — it never changes what is exported. The Pattern button on the canvas toolbar hides the solved pattern (and pauses re-solving) while you edit heavy outlines; Rebuild preview forces a fresh solve.

Adjusting Pattern Values

Type an exact value in a field, or drag its slider for quick adjustment. Fields accept simple arithmetic such as 25/2; the result replaces the expression when you press Enter. Hover a field or slider to see its allowed range. A value that is not a number or is outside the range is not applied: the field turns red, keeps what you typed, and its tooltip says why (for example Must be at least 0.001 mm) until you edit it again.

Sliders cover each field's full range. Ranges that span more than two orders of magnitude (such as Hex size, 0.001–20 mm) use a logarithmic track so small values stay easy to reach, and slider values are rounded to the field's precision so a drag never produces long decimals. Typed values are kept exactly. Integer controls, such as a seed or cell count, remain whole numbers.

Regions & Treatments

Every closed shape is a region. Click inside one on the canvas (or pick it in the Regions list), set the Pattern and Fill sections, and choose its Treatment:

  • Pattern + Fill, Pattern only, or Fill only
  • Engrave image — the region carries an image (the same as choosing Image as the pattern)
  • Cut only — the outline is cut but not filled; use it for lettering, logos, and holes
  • None — no treatment of its own

The line above the Treatment list names what you are editing: Region N · treatment with a region selected, or All regions · default treatment with nothing selected. Select several regions to edit them together; Apply to Selection copies the current settings to the selected regions. A region with a treatment of its own is automatically subtracted from the region containing it, so a pattern always flows around inner shapes.

Fill Modes

Mode Description
NoneNo fill. Only the pattern is generated.
LinesSeparate parallel hatch strokes at the chosen spacing and angle.
ZigzagHatch lines joined end to end for fewer travel moves.
CrosshatchTwo angled hatch passes.
ConcentricInward contour passes (angle does not apply).

Spacing must be at least 0.05 mm. Targets choose whether the fill covers the outline's open space, the closed pattern cells, or both; Keep pattern strokes alongside fill exports both, and unticking it gives fill-only output.

Presets

Apply loads the selected preset, Save stores the current pattern and parameters under the typed name, and More offers Delete and Manage presets… (rename, duplicate, import, export, and restore built-ins). Presets are exchanged as JSON (simple-stipple-presets/v1).

Built-in presets: Truchet (Arcs), Honeycomb (Fine/Standard/Bold), Stipple (Dense/Open), Brick, Mesh, and Voronoi. A preset saved with a retired pattern opens with its replacement, and the status line names the substitution.

Inspector (right) — Layers

  • Inspector (right): show, hide, select, and configure document layers. Region treatments remain in the left workflow rail and follow the selected region.

The fixed Export footer always shows the chosen format, enabled operations in machine order, and preflight warning count. Operation selection and ordering, geometry checks and findings, cleanup, and preview-quality controls stay in the secondary Output details and Export options sections above it.

Exporting

The primary button names the chosen format (Export DXF…, Export SVG…, Export FVI…, or Export Package… for a LaserStar folder); change it with Format. Export writes every enabled Output operation. It first runs preflight: if there are problems you can export anyway, cancel, or choose Show Issues to select and frame the affected outlines. It then re-solves the pattern at full quality, regardless of the preview quality — the status reads Solving at full quality for export… while that runs — and writes the file.
