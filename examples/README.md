# Simple Stipple sample projects

These files are small, safe-to-share SVG inputs for trying the application without preparing your own artwork.

## Engraving badge

Open `engraving-badge.svg` in **Draft**, then send the closed badge or center motif to **Pattern**. Try Honeycomb, Stipple Dots, or Voronoi, then inspect the generated paths before exporting.

## Trace-style leaf

Open `trace-style-leaf.svg` in **Draft** to edit the organic outline and vein paths. Use it to test layers, selection, dimensions, or custom pattern zones.

## Safe first run

1. Download one SVG file.
2. Open it with **Draft → Import…**.
3. Review the imported paths and units.
4. Send selected closed geometry to **Pattern**.
5. Generate a pattern and inspect it at high zoom.
6. Export only after checking the result in your machine software.

These examples contain no machine commands or laser parameters. Simple Stipple prepares geometry; it does not control laser hardware.
